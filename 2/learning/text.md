## Styling Text

Snowman supports most (but not all) of the syntax possibilities provided by the Marked library, including block-level elements such as headers, lists, blockquotes, code fences, and horizontal rules.

## Headers

| Syntax   | Code              |
|----------|-------------------|
| Header 1 | `# Header 1`      |
| Header 2 | `## Header 2`    |
| Header 3 | `### Header 3`    |
| Header 4 | `#### Header 4`   |
| Header 5 | `##### Header 5`  |
| Header 6 | `###### Header 6` |

## Styles

| Syntax   | Code         |
|----------|--------------|
| Strong   | `**Strong**` |
| Emphasis | `*Emphasis*` |

## Line Items

| Syntax           | Code             |
|------------------|------------------|
| Unordered Item   | `- Item`         |
| Unordered Item   | `* Item`         |
| Ordered Item     | `1. Item`        |
